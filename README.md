# 🎓 Student Career Guide

An interactive, web-based platform designed to guide students in identifying academic pathways, career opportunities, and personalized career choices based on their habits and qualifications.

---

## 🚀 Overview

**Student Career Guide** simplifies career decision-making for students across various academic stages (10th, Intermediate, ITI/Diploma, B.Tech, etc.). It helps users discover immediate academic pathways, job opportunities, and personalized career recommendations powered by habit and behavioral assessments.

---

## Key Features

* **User Authentication**: Secure Sign-Up and Login workflows for students.
* **Student Dashboard**: Personalized dashboard showing profile completion progress, current status, and quick-action updates.
* **Habit-Driven Career Discovery Engine**: A 15-question Dynamic Aptitude Matrix mapping lifestyle and behavioral preferences to relevant career domains.
* **Interactive Career Guidance**: Step-by-step guidance based on qualification stream (10th/Schooling, Intermediate, Diploma, B.Tech) with tailored pathways.
* **Profile Management**: Update academic details, branch, college, and personal information seamlessly.

---

## 🛠️ Tech Stack

* **Frontend**: HTML5, CSS3, JavaScript
* **Backend**: PHP
* **Database**: MySQL / MariaDB (managed via DBeaver / XAMPP)
* **Server**: Apache (XAMPP / Localhost environment)
